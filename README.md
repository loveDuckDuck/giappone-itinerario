# Giappone in 17 giorni

Itinerario del viaggio dal 18 novembre al 4 dicembre 2026: Kyoto, Osaka, Nara, Fuji, Hakone, Tokyo e Kamakura.

- `index.html`: la pagina (un solo file, senza dipendenze oltre ai font di Google).
- `itinerario-giappone.pdf`: la stessa pagina in PDF, con tutti i link cliccabili.

Per modificare l'itinerario basta cambiare `index.html`. Se cambia, va rigenerato anche il PDF.
